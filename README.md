# Bán János — Portfolio

Modern és reaktív személyes portfólió oldal Angular 15, Tailwind CSS, GSAP és Particles.js alapokon.

## Fő technológiák
- **Frontend:** Angular 15, TypeScript, Tailwind CSS, GSAP, Swiper
- **Mobil & IoT:** Ionic, Apache Cordova, Withings & Polar API
- **Backend:** Firebase (Firestore, Cloud Functions)

## Lokális indítás
```bash
nvm use 18
npm install
npm start
```
Az alkalmazás elérhető a `http://localhost:4202/` címen.
